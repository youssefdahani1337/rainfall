However here we only have "access" to one byte to override, the concept stays the same as before, just with a few extra steps; to denote more, we have to fill the buffer with the address of the shellcode we wanted to execute, then overridethe end byte, so that the rbp holds the address of the same buffer, so when the cpu does the rbp-8 operation to reach the return address, it will take our address instead of the actual return address and again Voila ! we got our hands on the system.
